# GM Command Center

Windows command center with 110+ built-in tools. Single executable, no installation needed.

## Features

- **System Management** — Uninstall Manager, Service Manager, Environment Variables, Hosts Editor, Power Plans, Scheduled Tasks
- **Network Tools** — DNS Changer, Network Connections, Traceroute, IP Config, Firewall Rules, Bandwidth Test
- **Power User Tools** — Window Inspector, Screen Ruler, Process Watcher, Quick Launcher, Always On Top
- **Hardware Info** — Disk Health, GPU Monitor, Battery Report, System Info Pro, Disk Benchmark
- **Utilities** — Screenshot OCR, File Locksmith, Clipboard Monitor, Sleep Timer, Crapware Detector
- **Developer Tools** — Text to Speech, Password Generator, Base64, JSON Tools, Regex Tester, API Tester
- **And much more** — 110+ tools in total

## Auto-Update

GM checks for updates automatically on startup. When an update is available:
1. A notification appears in the system tray
2. Click to download and restart
3. The new version replaces the old one automatically

## Download

Just run `gm.exe` — no installation required.
